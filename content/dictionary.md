本词典提供数学基础、现代数学与理论物理主要分支的中英文名称索引，方便继续编写定义与关联文章。
当前快照采集于 **2026-11-10**，收录 **4,525 个概念**，其中 **1,434 个**附有核对过对应关系的 nLab 链接。

其中 **4,205 项**有核验过的中英文 Wikipedia 对应页；新增 **320 项**在核验时未找到关联中文页，中文名称另有可靠依据：**305 项**采用正式审定名词，**15 项**采用学术文献用法。

这是有明确来源边界、持续扩充的词库，不能视为全部数学物理词汇的穷尽清单。

## 名称与来源

- 有中英文 Wikipedia 对应页的概念，两个页面必须对应同一 Wikidata 实体；中文主名称使用经核验的简体标题，原始页面标题与采集时版本保留在来源记录中。
- 没有找到关联中文 Wikipedia 页面的概念，也可依据可靠中文资料收录。译名优先采用[全国科学技术名词审定委员会](https://cnterm.cn/)公布的名词及[术语在线](https://www.termonline.cn/)记录；没有适用审定词条时，参考高校、研究机构和学术期刊的中英文用法，并标明“学术文献用法”。每项保留原文词对、发布机构、文献或术语编码、公布年份与核验日期。
- 新增译名逐项核对概念含义和学科语境，主名称采用简体。学术用法不等于唯一标准译名；仅有 Wikidata 中文标签或未经核对的直译不作为收录依据。正式名词中方括号内的字可省略，主名采用完整形式，来源写法及简称保留为别名。
- nLab 对应关系使用 Wikidata 的 [nLab 标识 P4215](https://www.wikidata.org/wiki/Property:P4215)，并与 [nLab 官方源码快照](https://github.com/ncatlab/nlab-content/tree/c35cfa6ed9b33a9d2455ff294b78df6c37ac2f4f)核对。没有明确对应时不猜测链接。
- 原有双语 Wikipedia 条目的简繁标题经官方 API 核验；繁体名称保留为搜索别名，其他来源别名取自 Wikidata 标签及别名。这部分来源核验不等于逐项人工审定；同一术语的地区译名、历史称呼和适用语境仍可能需要修订。
- 这里整理名称、链接和版本元数据，不转载原站的定义、证明或文章正文。Wikidata 结构化数据按 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing) 提供；原站文章的使用应遵循各自许可。

候选范围由 107 个 Wikipedia 学科分类的直接页面成员、510 个显式基础概念标题，以及 nLab 的 Wikidata 标识集合组成。
这能同时覆盖常见基础词和部分现代数学术语，但缺少可靠中文译名、身份对应尚未明确或超出这些来源范围的概念可能尚未正式收录。
“未找到关联中文页面”表示核验时英文页的中文语言链接和 Wikidata 中文站点链接均为空，并不排除存在尚未建立关联的中文文章；也不意味着该概念没有通行的中文专业名称。

## 与自己的文章关联

每个概念有稳定 ID，例如 `tensor-product` 和 `manifold`。可以直接在概念页面补充自己的定义、公式与例子，
也可以在单独文章的 frontmatter 中写入：

```yaml
concepts:
  - tensor-product
  - manifold
```

词典会自动列出关联文章。修改概念标题或译名时保留 ID，文章关联就会继续有效。
