# 概念树

这里维护网站的学科层级、发展脉络与词条归属。独立词典页继续提供中英文检索，
中文和英文 Wiki 目录则以概念树组织全部已收录词条。

- `foundations-algebra.json`：数学基础、代数、数论、离散数学。
- `analysis-geometry.json`：分析、拓扑、几何、概率与统计、数值数学。
- `physics.json`：物理及其数学方法。

数学基础的直接子分类固定为集合论、数理逻辑、范畴论。
节点的 `concepts` 存放 `content/concepts/` 中的稳定概念 ID，允许同一 ID 出现在多个分类；
交叉分类只增加入口，不复制概念页面，也不改动词条正文。
原始词库的 `subjects` 是来源采集与检索标签，不等同于经过整理的概念树。

## 层级与历史顺序

`children` 的数组顺序就是页面和侧栏的分支顺序。按学科形成、发展阶段和先修关系组织，
而不是按字母或拼音重排。`periodZh` / `periodEn` 描述一个研究方向的形成和发展时期，
不声称其中每个术语都在同一年诞生；同阶段可按学习关系排列核心概念。
`sources` 提供分支或历史参考，词条本身的来源仍保留在原概念页。

每个节点包含简体中文和英文名称、简介、概念列表及子节点。根 ID 对应现有学科 URL，
子节点 ID 以完整父 ID 加 `-` 开头，例如 `algebra-linear-tensors`。
生成器据此生成 `/zh/algebra/linear/tensors/` 和对应英文页。
修改 ID 会改变分类 URL；调整标题不改变概念词条 URL。

## 编辑与检查

1. 在对应 JSON 的节点中增删概念 ID，或调整分支；跨学科概念可以列在多个适当节点。
2. 新概念仍在 `content/concepts/` 中编写，填好稳定 ID 与中英文标题，再加入概念树。
3. 执行 `npm run tree:generate` 更新中英文分类页面。
4. 执行 `npm run check`、`npm test` 和 `npx quartz build`。

`tree:check` 已接入常规检查，会拒绝漏收词条、未知 ID、同节点重复、空分支、无效层级或过期页面。
每个概念页自动列出所有分类路径；这些导航不混入作者文章的 `concepts` 关联。
生成时从实际概念页读取当前中英文标题，保留作者修订。

分类页面的 `concept-tree:start` / `concept-tree:end` 注释之间由生成器维护。
作者可在标记之外添加导读、定义、例子和公式；重新生成时保留这些内容及额外 frontmatter 字段。
标题、分类路径、语言切换、导航顺序和成员列表等管理字段随 JSON 更新。
生成器不会覆盖没有管理标记的已有页面；重命名分类后也会提示处理旧页面，避免静默遗留过期分类。
